# Almighty Amp
My goal is to add all newer NUX amps (MKII series) to the mightier amp app.
I have started with mighty20mk2. All main funtions are working, I am willing to add the other ones but I cannot do it without help because I don't own these devices. So if you have a mighty40mk2 or mighty60mk2 and some free time, you can help me add these devices to the app.
The windows app is tested on windows 11 26H1 28000.3501, it might not work on old windows. you might also need to install Windows MIDI Services Tools and Windows MIDI Services Tools from this link https://github.com/microsoft/MIDI/releases

## Features
This app aims to cover all the functionality of the original app plus many enhancements:
- Ability to save presets locally on your mobile device and export them to share with others.
- Remote control using a MIDI controller or a HID device. Both USB and Bluetooth MIDI controllers are supported.
- Landscape mode.
- Improved Jam Tracks functionality. Select any audio file in your device, add events like loop points, preset changes and others at any point and play along.
- The app unlocks 8 secret amp models in Mighty Plug Pro, Mighty Space and Mighty 20 MKII: Twin Rvb, Class A15, Vibro King, Budda, Brit Blues, Match D30, Brit 2000 and Uber HiGain
- Tempo/Beat Trainer
- Various other enhancements.
- Experimental feature: Patches made for mighty plug pro can now be scanned and imported to Mighty 20 mkii. It's a work in progress and not perfected yet. Sometimes the imported parameters are not imported correctly but if you if you import it again, it will import correctly. so if you are importing a plug pro patch, I recommend scanning it twice or three times to make sure everything is imported correctly. Other bugs might exist in this feature. you can find patches in this website: https://mightypatches.com/
  please note that some reverbs/delays/amps/mods are supported in plug pro and unsupported in 20mkii. if these are present in the patch you are trying to import, the app will disable that block in the chain and gives a warning about the original settings. you can keep the block disabled or use a similar mod/reverb etc at your discretion.
